# secure_server_setup.sh

Bash-скрипт для быстрой и безопасной настройки SSH и Fail2ban на свежем Ubuntu/Debian-сервере: меняет порт SSH, отключает вход по паролю и включает защиту от перебора паролей — с интерактивными проверками, чтобы не потерять доступ к серверу.

## Что делает скрипт

- Интерактивно спрашивает порт для SSH (без значения по умолчанию — ввод обязателен) и проверяет его корректность.
- Проверяет, что на сервере уже есть SSH-ключ, прежде чем отключать вход по паролю.
- Обновляет систему и устанавливает `mc` и `fail2ban`.
- Делает резервные копии всех конфигов перед изменением.
- Обходит особенность Ubuntu 22.10+/24.04, из-за которой смена порта SSH требует полной перезагрузки сервера.
- Настраивает `sshd_config`: новый порт, вход только по ключу, запрет пустых паролей.
- Проверяет синтаксис конфигурации (`sshd -t`) перед перезапуском службы.
- Настраивает `fail2ban` с эскалацией времени бана и перезапускает его.
- В конце показывает сводку и статус служб.

## Требования

- Ubuntu (проверялось на версиях с systemd socket-активацией SSH — 22.10 и новее, включая 24.04) или Debian с `apt` и `systemd`.
- Запуск от root (`sudo`).
- **Уже настроенный SSH-ключ** в `~/.ssh/authorized_keys` на сервере — скрипт отключает вход по паролю, и без ключа вы рискуете потерять доступ.
- Интерактивный терминал — скрипт нельзя запускать через pipe, `cron` или без TTY (он специально завершится с ошибкой, а не выберет порт сам).

Скрипт не тестировался на RHEL/CentOS/Fedora (там другой пакетный менеджер и служба называется `sshd`, а не `ssh`).

## ⚠️ Перед запуском

Убедитесь, что можете зайти на сервер по ключу:

```bash
ssh -i ~/.ssh/id_ed25519 user@server
```

Если входа по ключу ещё нет — настройте его до запуска скрипта. Если ключей на сервере не найдётся, скрипт покажет предупреждение и спросит подтверждение, но лучше не полагаться на этот запасной вариант.

## Использование

```bash
chmod +x secure_server_setup.sh
sudo ./secure_server_setup.sh
```

Скрипт запросит порт для SSH и проведёт через 9 шагов настройки, показывая прогресс и результат каждого шага.

## Пошаговый процесс

| № | Шаг | Что происходит |
|---|-----|-----------------|
| 1 | Проверка прав доступа | Скрипт должен быть запущен от root |
| 2 | Выбор порта SSH | Запрашивает порт (1-65535), предупреждает про порт 22 и порты <1024, проверяет занятость порта |
| 3 | Проверка SSH-ключей | Ищет `authorized_keys`, при отсутствии — предупреждение и подтверждение |
| 4 | Обновление и установка пакетов | `apt update && apt upgrade`, установка `mc` и `fail2ban` |
| 5 | Резервное копирование | Копии `sshd_config`, `sshd_config.d/50-cloud-init.conf` с суффиксом `.bak.<дата-время>` |
| 6 | Отключение socket-активации SSH | При наличии `ssh.socket` переводит SSH в обычный режим службы (см. раздел ниже) |
| 7 | Настройка параметров SSH | Применяет порт и параметры аутентификации, проверяет конфиг (`sshd -t`), перезапускает SSH |
| 8 | Настройка Fail2ban | Создаёт `jail.local`, перезапускает и включает автозапуск |
| 9 | Проверка состояния служб | Показывает статус `ssh`, `fail2ban` и jail `sshd` |

## Итоговые параметры SSH (`sshd_config`)

| Параметр | Значение |
|---|---|
| `Port` | выбранный вами порт |
| `PubkeyAuthentication` | `yes` |
| `PasswordAuthentication` | `no` |
| `PermitEmptyPasswords` | `no` |

## Итоговые параметры Fail2ban (`jail.local`)

| Параметр | Значение |
|---|---|
| `bantime` | 30 минут, удваивается с каждым повторным баном (`bantime.factor = 2`), максимум 24 часа |
| `findtime` | 10 минут |
| `maxretry` | 3 попытки |
| `backend` | `systemd` |
| `ignoreip` | `127.0.0.1/8 ::1` |
| jail `sshd` | включён, слушает выбранный порт, лог `/var/log/auth.log` |

## После запуска — обязательно проверьте доступ

Скрипт сам об этом напомнит, но это критично: **не закрывайте текущую SSH-сессию**. Откройте новое окно терминала и проверьте новое подключение:

```bash
ssh -p <ваш порт> user@server
```

Только убедившись, что новое подключение работает, закрывайте старую сессию.

Полезные команды после установки:

```bash
fail2ban-client status sshd              # список забаненных IP
fail2ban-client set sshd unbanip <IP>    # разбанить IP
```

## Резервные копии

Перед любыми изменениями скрипт копирует существующие файлы с суффиксом `.bak.ГГГГММДДЧЧММСС`:

- `/etc/ssh/sshd_config`
- `/etc/ssh/sshd_config.d/50-cloud-init.conf` (если существует)
- `/etc/fail2ban/jail.local` (если существовал до запуска)

Чтобы откатиться, скопируйте нужный `.bak.*`-файл обратно поверх оригинала и перезапустите соответствующую службу.

## Технические детали

**Socket-активация SSH (Ubuntu 22.10+/24.04).** На современных Ubuntu SSH по умолчанию запускается через systemd socket-активацию: слушающий порт держит юнит `ssh.socket`, а не сам процесс `sshd`. Из-за этого обычный `systemctl restart ssh` не применяет новый `Port` из `sshd_config` — требовалась полная перезагрузка сервера. Скрипт обнаруживает этот случай и переводит SSH в классический режим (`systemctl disable --now ssh.socket && systemctl enable --now ssh.service`), как рекомендует `README.Debian` пакета `openssh-server` — после этого порт применяется обычным перезапуском, без перезагрузки.

**Проверка конфигурации перед перезапуском.** Перед `systemctl restart ssh` скрипт выполняет `sshd -t`. Если в конфиге ошибка, перезапуск не выполняется — это защита от потери доступа из-за опечатки.

**Обязательный интерактивный ввод порта.** У порта нет значения по умолчанию: пустой ввод отклоняется, а без интерактивного терминала скрипт завершается с ошибкой вместо того, чтобы выбрать порт самостоятельно.
