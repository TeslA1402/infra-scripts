# infra-scripts

Коллекция bash-скриптов для настройки и обслуживания Linux-серверов и инфраструктуры.

## Скрипты

| Скрипт | Назначение | Документация |
|---|---|---|
| `bootstrap_secure_server.sh` | Первичная настройка SSH и Fail2ban на Ubuntu/Debian | [docs/bootstrap_secure_server.md](docs/bootstrap_secure_server.md) |
